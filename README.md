# 📝 Web Simulasi Latihan Soal — TES HAIRIL

Aplikasi web simulasi ujian berbasis komputer (**CBT / CAT System**) pribadi yang dirancang khusus untuk latihan mandiri dengan antarmuka yang bersih, modern, dan profesional.

---

## ✨ Fitur Utama

- **Antarmuka CAT Profesional**:
  - Logo khusus **TES HAIRIL**.
  - **Timer Countdown Digital**: Hitung mundur waktu pengerjaan dengan peringatan visual saat sisa waktu < 3 menit.
  - **Pengatur Ukuran Teks (A- / A / A+)** untuk kenyamanan membaca soal.
  - **Navigasi Soal**: Tombol *Soal Sebelumnya*, *Ragu-Ragu*, dan *Soal Berikutnya / Selesai*.
  - **Daftar Soal Interaktif (Grid Map)** dengan indikator status warna:
    - ⬛ **Hitam**: Terjawab
    - 🟨 **Kuning**: Ragu-ragu
    - ⬜ **Putih**: Belum dijawab
    - 🟦 **Border Biru**: Soal yang aktif
- **Bank Soal Format JSON ([`questions.json`](questions.json))**:
  - Sangat mudah ditambah atau diedit.
  - Fitur upload file `.json` kustom langsung dari web.
- **Skoring & Pembahasan Lengkap**:
  - Skor akhir, statistik benar/salah/kosong, waktu pengerjaan, dan review kunci jawaban beserta pembahasan detail.
- **100% Responsif**: Nyaman digunakan di Laptop maupun Smartphone (HP).
